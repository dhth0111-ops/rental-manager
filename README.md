# 🏢 임대관리

개인용 임대관리 PWA입니다.

## 앱 실행
- GitHub Pages: https://dhth0111-ops.github.io/rental-manager/

## 주요 기능
- 임대물건 / 호실 관리
- 세입자, 연락처, 보증금, 월차임 관리
- 임대차 시작일 / 만기일 관리
- 첫 번째 · 두 번째 · 세 번째 계약 등 계약 이력 누적
- 계약별 계약서 사본 저장 및 다시 보기
- 계약갱신청구권 / 재계약 / 만기이사 기록
- 렌트홈 방식 참고 5% 증액 계산
- 미납월세 합계, 수선비, 날짜별 메모
- 앱 비밀번호
- 암호화 수동 백업 / 복원
